# deploy/nodes

Node bootstrap and agent packaging.

- `fedora/` will hold the systemd unit and the libvirt/VFIO bootstrap script (roadmap items P2.9 and P4.1).
- `macos/` will hold the LaunchDaemon plist and the Lima bootstrap script (roadmap items P2.9 and P4.2).
- `install-agent.sh` will install the agent binary and its config (roadmap item P2.9).
